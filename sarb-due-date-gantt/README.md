# SARB Due Date Heatmap

## Executive Summary

Keeping SARB (Solution Architecture Review Board) reviews on schedule requires knowing, at a glance, how much review workload is concentrated where and when, and which of it is already overdue. This capability turns a flat spreadsheet of SARB due dates into a single Solution-Architect-by-Month heatmap — dense enough to show the full Q4 2026–2027 horizon in one view, yet detailed enough that every individual Project/Idea is still one hover away — so leadership and architects can immediately spot overloaded months, overdue backlog, and workload imbalance across the team without manually scanning rows of dates.

## Business Process Flow

1. The user provides the **same Work List export used by the other SA skills** (or drops it into the shared Inputs folder) — it may contain every classification (Projects, Ideas, TechPass requests, SA NPD, NPD) in one file, distinguished only by the `Work Ref` prefix.
2. The tool keeps only **Projects** (`Work Ref` starting `PRJ`) and **Ideas** (`Work Ref` starting `ID`); TechPass, SA NPD, and NPD rows are dropped automatically since SARB due dates only apply to Projects/Ideas.
3. The tool automatically excludes items that already have a SARB Rating recorded (they've already been reviewed and no longer have a "pending" due date), unless told to include them.
4. The in-scope items are narrowed to a fixed review horizon — August 2026 through the end of 2027 — since that is the window leadership plans against; anything outside it is dropped.
5. Each item is classified as **Overdue** (due date already passed) or **Upcoming** (due date still ahead), measured against today's date (or a specified reference date), and grouped by Solution Architect and by due month.
6. A single heatmap is produced: Solution Architects down the side (busiest first), months across the top, and each cell showing a plain count of how many items are due that SA/month — with a bold orange outline whenever any of those are already overdue.
7. A single "Total" figure in the top-left corner reports the grand total of in-scope items, and a reference line marks exactly where today falls (proportionally within its month) so it's obvious where "overdue" ends and "upcoming" begins.
8. The finished chart is an interactive web page, set in a clean professional rounded sans-serif typeface — clicking any cell opens a details panel listing every item in it (reference number, name, status, exact due date), with a quick hover preview too — delivered to the shared Outputs folder for easy sharing.

## Technical Flow

- **Script**: `sarb_due_date_gantt.py`, run via `py .\sarb_due_date_gantt.py [--input PATH] [--as-of YYYY-MM-DD] [--include-approved] [--output-dir PATH]`.
- **Libraries**: `pandas` for tabular data handling, date arithmetic, and pivoting; `plotly.graph_objects`/`plotly.subplots.make_subplots` for the heatmap-plus-margin-bars layout; `openpyxl` for reading `.xlsx`/`.xls` input; and the standard library `csv` module for `.csv` input.
- **Input resolution**: if `--input` is omitted, the shared `_shared\sa_paths.py` helper's `latest_input("*.csv", "*.xlsx", "*.xls")` picks the newest matching file in `SA\Inputs`; otherwise the given path is used directly. `load_rows()` dispatches to `openpyxl` (first worksheet, row 1 as headers) or `csv.DictReader` based on file extension.
- **Filtering logic** (`build_dataframe`): rows are first checked against `is_project_or_idea()` (`Work Ref` matching `^(PRJ|ID)\d`, case-insensitive) — this keeps only Projects and Ideas and drops TechPass/SA NPD/NPD rows from the shared Work List export. Remaining rows without a parseable `SARB Due Date` are dropped. Rows are also dropped if the due date falls outside the fixed window **August 2026 (Aug 1, 2026) through the end of 2027 (Dec 31, 2027)** — nothing outside that range is charted. If a `SARB Rating` column exists in the source and the row has a non-blank rating, the row is excluded by default (already reviewed) — `--include-approved` disables this filter. Each remaining row is classified `Overdue` if `SARB Due Date < as_of` else `Upcoming`, and tagged with a `Month` period (`YYYY-MM`) for grouping.
- **Pivoting** (`build_heatmap_chart`): Solution Architects are ordered by total item count (descending). `df.groupby(["SA", "Month"]).size()` is pivoted into an SA x Month count matrix (`total`), reindexed against the full Aug 2026–Dec 2027 month list so every column exists even if empty; a second pivot (`overdue`) captures just the overdue counts per cell, used only to flag which cells get an outline (not displayed as a separate number). A parallel hover-text matrix lists every item (`Work Ref`, name, status, due date) in each SA/month cell, and the cell-text matrix renders a plain count.
- **Chart construction**: a single `go.Figure` with one `go.Heatmap` trace (no subplots, no margin bars). Numeric axis positions (`x_idx`/`y_idx`) are used instead of category strings so overdue cells can be outlined precisely: `fig.add_shape` draws a 3px orange (`#e67e22`) rectangle around every `(SA, month)` cell that contains at least one overdue item. The heatmap itself uses a `Blues` colorscale keyed to cell count with `showscale=False` (no colorbar/legend — the grid is self-explanatory), and `xgap`/`ygap` for grid separation. Month-axis tick labels are angled at -45° with a 13px font so all 17 months remain legible without overlapping. A single `fig.add_annotation` in the top-left corner (paper coordinates) renders `"Total: N"` as the one grand-total figure shown outside the grid. The "today" reference line is positioned at `month_index - 0.5 + (day_of_month - 1) / days_in_month`, so it lands at the correct fractional point within its month column (e.g. late in the month, not at the month's start) rather than always sitting at a month boundary. A global rounded-sans-serif `font` (Segoe UI Rounded / Varela Round / Century Gothic) is applied to the whole figure — title, axis ticks, annotation, and cell text — all rendered bold, with cell counts automatically switching to white text on the darkest cells and dark text elsewhere (via inline `<span style="color:...">` since Heatmap's `textfont.color` cannot take a per-cell array). The overall figure height scales with the number of Solution Architects.
- **Click-to-expand details**: each heatmap cell carries a `customdata` payload (an HTML details block listing every item's reference, name, status, and due date). `render_interactive_html()` wraps the Plotly figure's HTML (`fig.to_html(..., div_id="sarb-heatmap")`) with a styled `#sarb-detail-panel` div and a `post_script` that attaches a `plotly_click` listener to the heatmap div; clicking a cell writes its `customdata` into the panel. This keeps the chart itself uncluttered while making full item detail available on demand, in addition to the existing hover tooltip.
- **Output generation**: `render_interactive_html()` renders the figure to self-contained HTML (`fig.to_html(..., include_plotlyjs="cdn")`) plus the details panel and click handler, written to `SA\Outputs\sarb-due-date-gantt\` (or a custom `--output-dir`), named `SARB_Due_Dates_Heatmap.html`.
- **Edge cases handled**: missing Solution Architect (labeled `(Unassigned)`), months with zero items (blank cell), the as-of month falling outside the charted window (no reference line drawn), empty result set after filtering (raises a clear error), non-Project/Idea rows (TechPass/SA NPD/NPD, silently skipped), and mixed CSV/Excel input formats.

## Inputs

- The same Work List CSV or Excel export (first worksheet) used by the other SA skills, with these required columns: `Work Ref`, `Work Ref: Name`, `Work Ref: Solution Architect`, `SARB Due Date`. The file may include non-Project/Idea rows (TechPass, SA NPD, NPD) — they are filtered out automatically based on the `Work Ref` prefix.
- Optional column used if present: `SARB Rating` (used to exclude already-reviewed items by default).
- If `--input` is omitted, the newest `.csv`/`.xlsx`/`.xls` file in the shared `SA\Inputs` folder is used automatically.

## Outputs

- `SARB_Due_Dates_Heatmap.html` — a single interactive Solution-Architect-by-Month heatmap of every in-scope Project/Idea (Aug 2026 through 2027), with overdue cells outlined in orange, full item detail on hover, and a monthly total bar above the grid.
- Lands in `SA\Outputs\sarb-due-date-gantt\` by default (or a custom `--output-dir`).
